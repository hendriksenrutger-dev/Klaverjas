# Bronvermelding geluiden

`kaart-1.ogg` t/m `kaart-4.ogg` zijn de geluiden `cardSlide1.ogg` t/m `cardSlide4.ogg` uit
**Casino Audio** van **Kenney** (www.kenney.nl), vrijgegeven onder **CC0** (publiek domein):
http://creativecommons.org/publicdomain/zero/1.0/

Gebruikte kopie: https://github.com/db0/hypnagonia (map `assets/sounds`; de README daar vermeldt dat
deze geluiden van Kenney zijn en CC0). Alleen de geluiden zijn overgenomen, geen code uit dat project.
Het originele pakket "kenney_casinoaudio" (met licentiebestand "Creative Commons Zero, CC0") is ook te
vinden in https://github.com/nagillimnayr/solitaire-footpedal.

Het schudgeluid wordt in de app zelf opgewekt (`src/ui/geluid.js`).
