# Bronvermelding geluiden

Alle geluiden komen uit **Casino Audio** van **Kenney** (www.kenney.nl), vrijgegeven onder **CC0**
(publiek domein): http://creativecommons.org/publicdomain/zero/1.0/

| Bestand | Bron (Kenney Casino Audio) | Bewerking |
|---|---|---|
| `kaart-D.ogg` | `cardShove3.ogg` | hoogdoorlaat 900 Hz, 0,16 s (gekozen door Rutger uit zes varianten) |
| `schudden.ogg` | `cardShuffle.ogg` | hoogdoorlaat 300 Hz, ingekort tot 1,6 s |
| `deel.ogg` | `cardPlace2.ogg` | hoogdoorlaat 1000 Hz, 0,12 s (één pakje bij het delen) |

Overal: stilte bijgesneden, zachte uitloop, volume gelijkgetrokken, mono, Ogg Vorbis.

Gebruikte kopieën: https://github.com/pigdevstudio/assets (map `sandbox/audio/cassino_sfx`) en
https://github.com/db0/hypnagonia (map `assets/sounds`, met README die Kenney en CC0 vermeldt).
Het originele pakket met licentiebestand ("Creative Commons Zero, CC0") staat ook in
https://github.com/nagillimnayr/solitaire-footpedal (map `Assets/Imported/kenney_casinoaudio`).
Alleen de geluiden zijn overgenomen, geen code uit die projecten.
